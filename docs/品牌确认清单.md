# 品牌确认清单

未知项保持待确认；不得由开发自行编造价格、奖励比例或产品效果。

| 要确认的内容 | 当前状态 | 品牌方需给的材料 |
| --- | --- | --- |
| 网站主要用途：品牌展示 / 合作申请 / 真实下单 | 待确认；现有为品牌基础页 | 一句话用途与客户主要动作 |
| 正式产品名称、SKU、规格、库存、上下架 | 待确认 | 商品表 |
| 商品价格及是否公开 | 待确认 | 价格表与生效时间 |
| 品牌 Logo、真实图片及使用授权 | 待确认；现有为示意素材 | 原图、标识文件与授权 |
| 首页风格与文案 | 待确认 | 选定视觉样例和最终文案 |
| 合作申请字段及处理人员 | 待确认 | 必填字段、负责角色与联系方式 |
| 登录方式 | 待确认 | 短信 / 微信等方式与对应服务账号 |
| “我的订单”“我的团队”可见范围 | 曾要求入口，数据权限待确认 | 游客/会员/伙伴的权限表 |
| 邀请归属层级、绑定时点、冲突处理和有效期 | 待确认 | 版本化规则 |
| 积分充值、购买、退款、奖励及结算 | 待确认正式版本 | 财务流程和规则表 |
| 客服渠道及服务时间 | 待确认 | 真实电话、微信或客服入口 |
| 内容审批与上线验收人 | 待确认 | 负责人和验收记录 |

开发可先做数据结构、组件和错误态；依赖规则的生产业务须在对应材料确认后实现。完整客户资料与账户凭据不提交公开 GitHub。
