# 接口需求与验收标准

以下是建议接口契约，不是已实现 API。除已存在的前端请求路径外，后端可协商路径，但须同步更新前端。日期使用带时区的 ISO 8601，金额使用整数最小货币单位，积分使用整数。生产数据不写进示例或公开仓库。

## 接口清单

| 接口 | 权限 | 必需行为 |
| --- | --- | --- |
| GET /api/products | 公开 | 商品 ID、名称、规格、图片、上下架状态；价格只在确认后返回 |
| GET /api/products/{id} | 公开 | 单一商品数据；下架/不存在有明确状态 |
| POST /api/applications | 公开，防重复与限频 | 接收已确认字段和规则版本；返回申请 ID；可查处理状态的方式由品牌方确认 |
| POST /api/invite/validate | 公开，限频 | 与现有 JS 兼容：请求 `{code}`；响应 `{valid: true}` 或 `{valid: false, message}`；不泄露邀请码持有人资料 |
| GET /api/me | 登录 | 返回本人 ID、展示名称、可用权限；未登录返回 401 |
| GET /api/me/orders | 登录 | 按本人身份过滤，支持状态筛选和游标分页 |
| GET /api/me/orders/{id} | 登录 | 验证订单所有权；他人订单不可读取 |
| GET /api/me/team | 获授权伙伴 | 只返回授权关系和脱敏字段；不允许客户端传任意用户 ID 越权 |

登录、申请具体字段、关系绑定和交易接口待品牌规则确认后补契约。校验邀请码仅验证来源，不自动建团队关系或发奖励。

## 错误处理

- 401：提示登录；403：提示无权限；404：商品/记录不存在；409：重复/冲突；429：稍后重试；5xx：重试入口。
- 网络失败保留填写内容，成功前不显示“已提交”。写入接口接受幂等键；重试不得生成第二笔订单/申请/奖励。
- 失败不能替换成假余额、假订单、假团队或假归属。演示数据只能在明确的测试环境使用。

## 手机验收

| 场景 | 通过标准 |
| --- | --- |
| 360、390、430 CSS 像素宽度 | 无横向滚动；正文可读；控件触点至少 44px；底部内容不被浮窗遮住 |
| iPhone Safari、Android Chrome、微信内置浏览器 | 分别记录实测机型、浏览器版本、结果；模拟器通过不等于真机通过 |
| 首页轮播 | 点击切换正常；减少动态效果偏好下不自动轮播 |
| 浮窗导航 | 点击定位正确；滚动高亮对应区域；有安全区余量 |
| 商品分享 | 三个商品参数分别打开对应详情；非法参数不报错；关闭后可正常浏览 |
| 分享与海报 | 空邀请码生成公开链接；有效/无效/离线各有正确状态；二维码能扫描到对应链接 |
| 海报保存 | HTTPS/本地 HTTP 下生成 PNG；iOS/Android 可长按保存；本地 file 协议可能限制 Canvas，不作为验收环境 |
| 申请合作 | 成功收到编号；失败能重试；重复操作不产生重复记录 |
| 身份与隐私 | 游客不可读订单/团队；用户 A 不能读取 B 的记录；退出后不可回读敏感内容 |
| 交易阶段 | 首购/复购/退款/重复请求/并发请求有订单与账务对账证据；审批是独立登录动作 |

## 交接与部署

PR 描述填写：变更、页面截图、接口版本、验证结果、待确认项。部署前需确认域名配置、商品文案、接口鉴权、备份恢复、回滚办法。当前仓库没有后端，也没有自动部署生产服务器的能力。
