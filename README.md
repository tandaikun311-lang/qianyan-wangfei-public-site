# 芊颜王妃｜对外品牌合作中心基础版

这是面向客户和合作伙伴的移动优先静态前端基础版。品牌方可以直接下载本仓库，在本地打开或继续修改，确认后再部署到正式服务器。

## 当前包含

- 品牌首页与图片轮播
- 产品组合与产品详情弹窗
- 合作流程说明
- 分享链接生成
- 分享海报与二维码生成
- 手机端固定底部浮窗导航：首页、产品、流程、分享

## 本地预览

直接双击 `index.html` 即可预览。也可以在仓库目录运行：

```bash
python3 -m http.server 8080
```

然后打开 <http://127.0.0.1:8080/>。

## 继续修改

- 页面结构：`index.html`
- 视觉样式：`visual-polish.css`
- 分享链接和海报：`share-tools.js`
- 二维码生成：`qrcode-generator.js`
- 图片资源：`assets/`

## 正式部署

当前线上公开入口：<https://tandaikun.com/partner/>

修改完成后，请先在本地检查手机端，再将确认后的静态文件部署到服务器。仓库不包含服务器密钥、Workbench 凭据、Nginx 配置或内部后端代码。

## 持续开发交接

- [同类产品与开发路线](docs/同类产品与开发路线.md)
- [品牌确认清单](docs/品牌确认清单.md)
- [接口与验收标准](docs/接口与验收.md)

邀请码校验依赖后端，本仓库没有该接口；公开链接和海报是现有基础功能。订单、团队、真实申请、身份与财务功能按开发路线逐项接通。

海报验收请使用上面的本地 HTTP 服务；直接打开文件可能被浏览器限制 Canvas 图片导出。

基础交互回归：`node scripts/check-interactions.cjs`。该检查验证商品参数与导航状态；不代替真实手机、二维码扫描和后端联调验收。
